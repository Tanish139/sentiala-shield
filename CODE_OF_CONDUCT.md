# Code of Conduct

## Our pledge

We are building a defensive security tool and expect everyone
participating in this project — maintainers, contributors, and comment
alike — to act with honesty and respect.

## Standards

**Expected:**

- assume good faith, especially from newcomers and non-native speakers
- critique code, not people
- be honest about limitations, uncertainty, and mistakes
- respect privacy — do not post other people's data, even in bug reports

**Unacceptable:**

- harassment, personal attacks, or discriminatory language
- posting real credentials, malware samples, or live phishing links
  without warning and a safe handling plan
- using this project to harass, surveil, or harm anyone
- dogpiling, brigading, or deliberately hostile tone

## Enforcement

Report issues to the maintainers via a private channel (repository
security advisories or maintainer email). Reports are handled
confidentially. Maintainers may remove content and ban participants who
violate these standards.

## Credit

This code of conduct is deliberately short. It borrows the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/).
